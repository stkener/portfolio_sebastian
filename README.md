# 🌐 Personal Portfolio

A modern and responsive personal portfolio built to showcase my projects, academic experience, and software development skills.

The website serves as a central place where recruiters, collaborators, and anyone interested in my work can learn more about my background and explore my projects.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/stkener/portfolio_sebastian.git
```

Go to the project directory:

```bash
cd portfolio_sebastian
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```
